# 四大名著人物别名词典（语料接地版）
# ============================================================================
# 格式：规范名 <TAB> 别名1 <TAB> 别名2 ...   （UTF-8，制表符分隔）
#   * 以 # 开头的行为注释，加载时应整行跳过（含行内注释用法时请只跳过整行）
#   * 组内第 1 个字段是规范名（归一目标），其余是别名
#   * 空行忽略
#
# 使用方式（归一必须【对称】：文档侧与查询侧调用同一个函数）：
#   1) 把 规范名 + 所有别名 一起收进一张 surface -> canonical 的表；
#      规范名映射到自身（恒等映射）。
#      !!! 规范名必须参与匹配 !!! 否则 "鲁智深" 会先被 "智深" 命中，
#      替换成 "鲁鲁智深"（本文件里 智深⊂鲁智深、金角⊂金角大王、
#      悟空⊂孙悟空、宝玉⊂贾宝玉 等 40 余组都会踩这个坑）。
#   2) 替换时 【最长优先】：先处理所有更长的 surface，再处理短的。
#      典型：诸葛孔明>孔明，关云长>云长，甄士隐>士隐，齐天大圣>（大圣已剔除）。
#      实现建议：把所有 surface 按长度降序排序，用单次左到右扫描，
#      命中即整体替换并跳过已消费的字符（不要先替换短的再替换长的）。
#   3) 归一后 文档与查询落在同一词面空间，BM25 才能把 "孔明" 与 "诸葛亮"
#      算作同一个词。
#
# 收录标准（为什么不长）：别名必须在 books/ 中【真实出现】且【不指向别的实体】。
#   * 语料实测：见 tools/verify_lexicon.py 的输出（每个词的出现次数）。
#   * 竞争性用法（同一串字在语料里还指别人/别物）出现 >=2 次 -> 一律剔除，
#     即使该别名高频（行者/大圣/猴王/公明 都是这样被砍掉的，见文末剔除表）。
#   * 竞争性用法仅 1 次 -> 收录并在该行上方注释标注残余。
#   * 本语料是【节本】：水浒传只到第 23 回、红楼梦只到第 68 回，因此
#     语料里根本没有的写法（李逵/花荣/戴宗/潘金莲/甄宝玉/白骨精…）一律不收。
#
# 已知残余风险（load-bearing 的诚实声明）：
#   * 通灵宝玉(4 次, 红楼梦)：含 "宝玉"，会被替换成 "通灵贾宝玉"。同指一物（通灵
#     宝玉就是贾宝玉的命根子），语义未跑偏，但字面被改写。如需零损伤，调用方
#     可在归一前把 "通灵宝玉" 加入屏蔽表（见文末"建议屏蔽表"）。
#   * 宝玉 在 水浒传(1 次 "嵌宝玉环条")/西游记(1 次) 里是普通名词"宝石"，占比 0.09%。
#   * 先主 在西游记 1 次指"先主李渊"；后主 在红楼梦 1 次指"陈后主"。
#   * 三寸丁 命中 "三寸丁谷树皮"(武大诨名全称) 时会被改写成 "武大谷树皮"，同指武大。
#   * 悟空 在 "假悟空/真悟空"(各 1 次, 指六耳猕猴) 处会被改写成 "假孙悟空"。
#   * 凤雏 在红楼梦 1 次是成语 "龙驹凤雏"（指人，非庞统）。
#   * 学究 在红楼梦 1 次是泛称 "二位学究"。
#   * 【安全的一类，刻意保留】卧龙冈(8 次, 三国) 含 "卧龙" -> "诸葛亮冈"。
#     改写串不与任何人物名相撞，且该段落本就是讲诸葛亮；对称替换下查询侧
#     也把 "卧龙冈" 写成 "诸葛亮冈"，两侧一致 -> 不影响召回。同理保留：
#     高太尉陷/蔡太师庆/孟德新书/三寸丁谷树皮 等"人名+实词"的组合。
#     对照【有害的一类】：龙子龙孙(10 次, 全在西游记) 会变成 "龙赵云孙"，
#     在龙宫段落里凭空造出实体词 "赵云" -> 查询"赵云"跨书召回西游记，
#     所以 子龙 被剔除（见文末剔除表）。
#   * "重复归一"（同指、无害，但会让字面变啰嗦）：关羽关羽(汉寿亭侯关公, 5)、
#     王熙凤姐(凤姐姐, 13)、李李纨(李宫裁, 16)、陈唐僧(陈玄奘, 14)、
#     唐唐僧(唐圣僧, 12)、龙王东海龙王(龙王敖广, 4)、
#     孙悟空孙悟空(齐天大圣孙悟空, 14)、宋江宋江(及时雨宋公明, 4)。
#   * 老君——未收（红楼梦有茶名"老君眉"）；龙王/金星/二郎/菩萨/长老/呆子/行者
#     ——未收（另指他人），详见文末剔除表。
# ============================================================================
