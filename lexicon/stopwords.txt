# 示例领域停用词表（高频低信息虚词，语料接地版）
# 说明：本文件是「垂直领域 RAG」的一个领域停用词示例；换领域时按同一格式整表替换即可。
# ============================================================================
# 格式：每行一个词，行内 "#" 之后全是注释（含该词在 RAG_DATA_DIR 各文档中的
#       出现总次数与收录理由）。加载方式：line.split("#")[0].strip()，
#       跳过空行。UTF-8。
#
# 用途：稠密通道不受影响；稀疏通道（BM25）过滤这些词，避免 "之/也/曰/的"
#       这类语法词刷高所有文档的分数、稀释真正的实词权重。
#
# 【硬性禁止（本表已全部排除，`python chatbot.py lexicon` 会强制校验）】
#   否定词：不 无 未 莫 非 没 别  —— 一旦过滤，"张三不读书" 与 "张三读书"
#           归一成同一个查询，语义被彻底破坏。本表一个都没有。
#   程度词：很 太 最 更 极 甚 颇 稍 略  —— 同理，"大闹" 与 "小闹"、
#           "最强" 与 "较弱" 的差别会被抹平。
#
# 【谨慎排除的"半实义词"（也不是停用词，理由已注明）】
#   道(20235) 说(9338)   —— 古白话里 "道/说" 既是最常用动词又承载最核心的
#                     对话语义（谁对谁说了什么），且 "道理/说道/难道/知道"
#                     等复合切分不稳定 -> 不收。
#   将(6713)   —— 三国里 "将" 绝大多数是实义（将军/众将/一将）-> 不收。
#   把(3079)   —— "把酒/一把/把守" 实义比例高 -> 不收。
#   教(2101) 叫 使 令 —— "教头/叫喊/使者/令箭" 均为实义 -> 不收。
#   了(21060) 着(15097) 得(12161) 过 —— aspect 助词与实义动词（了结/穿着/
#                     得到/经过）在古白话里高度混用 -> 不收。
#   是 有 在      —— 判断/存在义，承担选择信息（"谁是谁"）-> 不收。
#   到 至         —— 位移实义动词 -> 不收。
#   何(2276)      —— 三国人名 "何进/何太后" 用字 -> 不收。
#   云(1499)      —— 三国人名 "赵云/关云长" 用字 -> 不收。
#   地(2570)      —— "土地/地方/田地" 实义 -> 不收。
#   阿(235)       —— "阿斗/阿瞒" 前缀 -> 不收。
#   不在/不曾/未及/莫不/无非 —— 内部含否定词 -> 不收。
#   原来 只见      —— 章回套语但含 "原/见" 实义（"只见" = 只看见）-> 不收。
#
# 已验证：本表收录的词交给 jieba 分词时不会伤到实体，例如
#   成都/都城/建都 -> 整词（都 不会切出来）；赵云/关云长 -> 整词；
#   何进/何太后 -> 整词；将军/教头/林教头 -> 整词；土地/地方 -> 整词。
# ============================================================================
